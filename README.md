## 🚀 Featured Flagship Projects

### 🧠 [omni-modal-pipeline](https://github.com/Coder-0X/omni-modal-pipeline)
> **High-Throughput Asynchronous Cross-Modal Attention & Streaming Perception Engine**  
- **Architecture**: Decoupled asynchronous sensory encoders for spatial visual patches (ViT) and temporal acoustic frames (log-mel mel-spectrograms + VAD).
- **Core Innovation**: Scaled dot-product cross-modal attention with dynamic softmax modality gating ($\gamma_t, \gamma_v, \gamma_a$) and unit normalization.
- **Performance**: Measured **P50 Latency of 21.12 ms** and **47.3 QPS throughput** with native FastAPI REST and WebSocket streaming.
- **Tech Stack**: Python 3.11, FastAPI, WebSockets, Pytest, Docker, GitHub Actions CI.

### ⚡ [ShipIt-AI](https://github.com/Coder-0X/ShipIt-AI)
> **Multi-Surface Developer Intelligence & Automated Release Orchestration Platform**  
- **Multi-Surface**: Ingests raw git diffs across Web (Next.js 16), Chrome Extension (MV3 Sidepanel), and Google Workspace (Docs/Gmail Add-on).
- **Engine**: 4-stage reasoning pipeline powered by Google Gemini, featuring AST diff parsing, secret/PII redaction, commit health scoring, and multi-persona synthesis.
- **Ecosystem**: Full integration with Jira release hubs, Slack block-kit broadcasts, and Supabase audit logs.
- **Tech Stack**: Next.js 16, TypeScript, TailwindCSS v4, Google GenAI SDK, Supabase, Jest, Stripe.
